Scene 模块：World、Stage、HDRI

scene.py 是 render-usd 的舞台管理者。它负责初始化 Isaac Sim World、加载 USD 资产、设置 HDRI 环境光照，以及管理语义标签。

init_world()：World 的诞生

scene.py
from omni.isaac.core import World

def init_world(stage_units_in_meters=1.0, physics_dt=0.01, rendering_dt=0.01):
    world = World(
        stage_units_in_meters=stage_units_in_meters,
        physics_dt=physics_dt,
        rendering_dt=rendering_dt,
    )
    world.reset()
    return world

World 是 Isaac Sim 的核心运行时对象。它同时管理物理步长和渲染步长。虽然 render-usd 不做物理仿真，但仍需要调用 world.step(render=True) 来推进渲染管线。

语义标签：BBox 的前提

add_update_semantics(prim, semantic_label="instance", type_label="class") 给 Prim 打上语义标签。这不是为了人类阅读，而是为了让 BoundingBox2D/3D annotator 能识别出「这个像素/这个框属于哪个物体」。没有语义标签，BBox annotator 就找不到目标。
