Glossary 中英术语表

按字母顺序排列的术语速查表，保留英文原词并给出中文释义。

English中文释义
Alpha CompositingAlpha 合成，将前景与背景按透明度混合
Annotator（Omniverse）渲染后处理节点，用于提取特定通道数据
Azimuth方位角，球坐标系中绕 Z 轴的水平角度
Bounding Box (BBox)包围盒，包含一组几何元素的最小轴对齐长方体
BVH (Bounding Volume Hierarchy)层次包围盒，加速光线-场景求交的数据结构
Carbonite (carb)Omniverse 的内核层，提供插件、配置、日志等基础设施
DomeLight穹顶灯，模拟全局环境光照的球形光源
Elevation仰角，球坐标系中相对于水平面的垂直角度
Extent（USD） authored 包围盒，由创作者预计算并存储
HDRI高动态范围图像，用于环境光照的 360° 全景照片
Isaac SimNVIDIA 的机器人仿真与渲染平台
MDLMaterial Definition Language，NVIDIA 的声明式材质语言
Omniverse KitOmniverse 的应用框架，管理扩展生命周期
PathTracing路径追踪，基于蒙特卡洛积分的全局光照算法
Prim（USD）场景图的基本节点单元
RT CoreNVIDIA GPU 中专用于光线追踪的硬件单元
RTXNVIDIA 的实时光线追踪技术平台
SPP (Samples Per Pixel)每像素采样数，决定 PathTracing 图像质量
Stage（USD）场景描述的顶层容器，对应一个打开的数据库
USDUniversal Scene Description，皮克斯开源的场景描述格式
