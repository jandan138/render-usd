RTX hardware：从 Turing 到 Ampere

为什么 RTX GPU 能让 PathTracing 从「离线数小时」变成「准实时」？秘密在 RT Core 和 Tensor Core 里。

RT Core 做什么

RT Core 是 NVIDIA 从 Turing 架构开始引入的专用硬件单元。它只做两件事，但做得极快：

  • BVH Traversal：遍历加速结构，找到光线可能击中的三角形组
  • Ray-Triangle Intersection：精确计算光线与三角形的交点和重心坐标

在 Turing 之前，这两个操作必须由 CUDA core 用软件实现。RT Core 的硬件加速使得 RayTracing 的性能提升了约 10×。

Tensor Core 与 Denoising

Tensor Core 原本为深度学习矩阵乘法设计。在渲染管线中，它被用于：

  • DLSS (Deep Learning Super Sampling)：低分辨率渲染 + AI 上采样到高分辨率
  • Denoising：PathTracing 每帧采样数少（SPP 低），噪声大。Tensor Core 加速的神经网络可以在几毫秒内把噪声图变成干净图。

为什么 render-usd 需要 RTX

render-usd 的 CONFIG 里指定了 "renderer": "PathTracing"。PathTracing 需要追踪大量光线，没有 RT Core 的 GPU 运行 Isaac Sim 会非常缓慢，甚至无法达到可接受的收敛质量。

硬件要求：render-usd 的 README 明确要求「NVIDIA GPU with RTX support」。这不是为了炫技，而是 PathTracing 在 non-RTX GPU 上 fallback 到 CUDA software raytracing 后，性能不足以支撑批量生产。
