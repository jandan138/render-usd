六步数据流总览

从 CLI 参数到 PNG 文件，render-usd 内部经历了六个严格定义的阶段。理解这个流程，是定位任何 bug 的前提。

六步数据流

Step 1 · Input
用户通过 CLI 提供 USD 文件路径或目录。CLI 解析参数，收集 MDL 搜索路径。

Step 2 · Init World
RenderManager 调用 init_world() 创建 Isaac Sim World 对象。

Step 3 · Setup Scene
Scene 加载 USD stage，设置 HDRI DomeLight，初始化环境。

Step 4 · Setup Camera
Camera

Step 5 · Rendering Loop
RenderManager 遍历每个资产和每个视角，调用 world.step(render=True)，提取 sensor 数据。

Step 6 · Output
Alpha 合成后保存 PNG，记录元数据，可选绘制 BBox 边框。
