RTX PathTracing 的工作方式

Isaac Sim 默认使用 RTX PathTracing。它的流程可以简化为：

  1. 从相机传感器每个像素发射 primary ray
  2. RT Core 用 BVH traversal 快速找到与场景的交点
  3. 在交点处采样 BRDF，发射 secondary ray 追踪间接光
  4. 重复直到命中光源或 Russian Roulette 终止
  5. 多帧累积（SPP: Samples Per Pixel）降低噪声
From GAMES101
Assignment 7 里你写的 PathTracer::castRay() 是 CPU 单线程、暴力遍历三角形。RTX PathTracing 把这个过程搬到了 GPU，用 BVH 加速求交（O(log n) 代替 O(n)），并且用 Tensor Core 做 DLSS / denoising。
render-usd 的配置：在 cli.py 中，CONFIG = {"headless": True, "anti_aliasing": 4, "multi_gpu": False, "renderer": "PathTracing"} 显式指定了 PathTracing 渲染器。
