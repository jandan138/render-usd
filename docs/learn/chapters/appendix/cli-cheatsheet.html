CLI Cheat-sheet

常用命令速查。

单文件渲染

bash
python -m render_usd.cli single \
  --usd_path /path/to/asset.usd \
  --output_dir ./output \
  --naming_style view \
  --overwrite

自定义目录批量渲染

bash
python -m render_usd.cli render_custom \
  --assets_dir /path/to/assets \
  --naming_style view \
  --chunk_id 0 \
  --chunk_total 10 \
  --overwrite

GRScenes-100 分布式渲染

bash
python -m render_usd.cli grscenes100 \
  --chunk_id 0 \
  --chunk_total 100 \
  --naming_style view \
  --overwrite

环境变量

bash
export PYTHONPATH=$PYTHONPATH:$(pwd)/src
export MDL_SYSTEM_PATH=/path/to/mdl:/another/mdl
source miniconda/bin/activate render-usd
