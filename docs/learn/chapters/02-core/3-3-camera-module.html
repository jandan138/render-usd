Camera 模块：Spherical Look-At

camera.py 封装了 Isaac Sim Camera 传感器的创建、配置和数据提取。其中最精妙的部分是 set_camera_look_at()——用球坐标自动环绕物体。

init_camera()：创建传感器

camera.py
from omni.isaac.sensor import Camera

def init_camera(camera_name="camera", image_width=640, image_height=480,
                position=np.array([0.0, 0.0, 0.0]),
                orientation=np.array([0.0, 0.0, 0.0, 1.0])):
    camera = Camera(
        prim_path=f"/World/{camera_name}",
        resolution=(image_width, image_height),
        position=position,
        orientation=orientation
    )
    return camera

注意 Camera 是 Isaac Sim 的传感器类，不是简单的矩阵容器。它在 USD Stage 上创建了一个真实的 Prim，渲染器会「看到」它并从这个视角生成图像。

set_camera_look_at()：球坐标定位

这是 render-usd 相机系统的核心算法。输入是目标中心点、方位角（azimuth）、仰角（elevation）、距离（distance），输出是相机的世界坐标和朝向 quaternion：

camera.py (核心逻辑)
def set_camera_look_at(camera, target, distance=0.4, elevation=90.0, azimuth=0.0):
    elev_rad = math.radians(elevation)
    azim_rad = math.radians(azimuth)
    offset_x = distance * math.cos(elev_rad) * math.cos(azim_rad)
    offset_y = distance * math.cos(elev_rad) * math.sin(azim_rad)
    offset_z = distance * math.sin(elev_rad)
    camera_position = target_position + np.array([offset_x, offset_y, offset_z])
    rot = R.from_euler("xyz", [0, elevation, azimuth - 180], degrees=True)
    quaternion = rot.as_quat()
    # reorder to Isaac Sim convention (w, x, y, z)
    quaternion = np.array([quaternion[3], quaternion[0], quaternion[1], quaternion[2]])
    camera.set_world_pose(position=camera_position, orientation=quaternion)

视角映射表

remder-usd 默认生成 4 个视角，对应的球坐标参数如下：

视角名Azimuth方向含义
front0°+X从物体正前方看
left90°+Y从物体左侧看
back180°-X从物体正后方看
right270°-Y从物体右侧看

Elevation 固定为 35°，即「略俯视的高角度」，避免地平线遮挡，同时展示物体顶面细节。

From GAMES101
你的课堂 renderer 里，相机位置是手动设的 (0, 0, 5)。render-usd 的相机位置是数据驱动的：先算物体的 bounding box，再据对角线长度决定 distance，确保任何大小的物体都能完整入镜且占画面 60-65%。

setup_camera()：挂载 Annotators

setup_camera() 负责给 Camera 挂载各种输出通道：

  • add_distance_to_image_plane_to_frame() → Depth
  • add_bounding_box_2d_tight_to_frame() → 紧包围盒
  • add_bounding_box_2d_loose_to_frame() → 松包围盒
  • add_semantic_segmentation_to_frame() → 语义掩码

这些 annotator 在 initialize() 时注册到渲染管线，每帧自动更新。
