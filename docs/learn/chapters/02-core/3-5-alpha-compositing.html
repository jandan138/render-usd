Alpha 合成：白色物体生存指南

这是 render-usd 中最具「产品思维」的设计之一：用 HDRI 照明，但把背景抠掉，换成可控的纯色背景。解决了白色物体在白色 DomeLight 下消失的千古难题。

问题：白色物体 + 白色背景 = 消失

物理学原理很简单：物体的颜色 = 它反射的光的颜色。一个白色杯子之所以看起来白，是因为它几乎把所有照射到它身上的光都反射回来了。

如果背景也是白色，灯光也是白色，杯子反射了白光，背景也是白光——两者完全融为一体。就像在白纸上用白色笔画画。

方案：绿幕原理

电影工业用了几十年的 chroma key（绿幕/蓝幕）技术，核心是分两步：

  1. 真实打光：绿幕本身不会出现在最终画面，但灯光真实地照亮了演员
  2. 后期抠像：把绿色区域标记为透明，替换成太空、城市等背景

render-usd 的做法完全一样，只是「绿色」变成了「alpha=0」：

  1. 用 HDRI DomeLight 提供真实环境光照（物体被自然照亮）
  2. 用 backgroundZeroAlpha 把背景区域的 alpha 设为 0
  3. 在 Python 里用 alpha compositing 公式把透明背景换成深灰色

RTX backgroundZeroAlpha 四件套

scene.py
settings = carb.settings.get_settings()
settings.set("/rtx/post/backgroundZeroAlpha/enabled", True)           # 开启背景透明
settings.set("/rtx/post/backgroundZeroAlpha/backgroundComposite", False)  # 不自动合成背景
settings.set("/rtx/post/backgroundZeroAlpha/outputAlphaInComposite", True) # 输出保留 alpha
settings.set("/app/captureFrame/setAlphaTo1", False)                  # 不要强制 alpha=1

这四个设置缺一不可，共同确保：

  • 物体像素：alpha = 255（完全不透明）
  • 背景像素：alpha = 0（完全透明）
  • 边缘像素：alpha 介于 0-255（抗锯齿过渡）

Alpha 合成代码

renderer.py (核心合成)
rgba = get_src(camera, "rgba")                          # H x W x 4
alpha = rgba[:, :, 3:4].astype(np.float32) / 255.0     # 归一化到 [0, 1]
bg = np.full_like(rgba[:, :, :3], 40, dtype=np.float32) # 深灰色 RGB(40,40,40)
rgb = (rgba[:, :, :3].astype(np.float32) * alpha + bg * (1.0 - alpha)).astype(np.uint8)
$$ \text{output} = \text{foreground} \times \alpha + \text{background} \times (1 - \alpha) $$
效果：alpha=1 的像素保留物体本身；alpha=0 的像素显示深灰色；半透明边缘自然过渡，避免锯齿。
