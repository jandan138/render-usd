跑通一次完整渲染

理论到此为止。让我们用一条命令，把前面学过的所有概念串起来，跑出第一张 thumbnail。

环境准备

bash
# 1. 激活 conda 环境
source miniconda/bin/activate render-usd

# 2. 设置 PYTHONPATH
export PYTHONPATH=$PYTHONPATH:$(pwd)/src

# 3. 验证 Isaac Sim 可用
python -c "from isaacsim import SimulationApp; print('OK')"

单文件渲染

bash
python -m render_usd.cli single \
    --usd_path /path/to/your/asset.usd \
    --output_dir ./output \
    --naming_style view

预期输出：

output/
output/
├── front.png
├── left.png
├── back.png
└── right.png

自定义目录批量渲染

bash
python -m render_usd.cli render_custom \
    --assets_dir /path/to/GRScenes_assets \
    --naming_style view \
    --chunk_id 0 \
    --chunk_total 10

观察日志

正常运行的日志应该包含这些关键词：

  • [Scene] HDRI environment loaded: ... → 光照设置成功
  • [1/529] Rendering: ... → 批量进度
  • [Memory] Garbage collected after ... → 内存清理
  • [CLI] Isaac Sim closed successfully → 干净退出
如果看到红色：检查 MDL 路径是否正确注册。如果看到全黑：检查 HDRI 是否加载成功。如果看到 exit code 139：检查 cleanup() 是否被调用。
