Authored extent vs mesh points：两条路线的较量

Bounding Box 是相机定位的唯一依据。但「物体的边界」有两种定义方式：USD 作者声明的 extent，和实际几何顶点的包围盒。它们可能不一致，而 render-usd 必须处理这种不一致。

Authored Extent：USD 的「官方声明」

USD 的 UsdGeom.Boundable 类型有一个 extent 属性，是资产创作者预先计算的包围盒。通过 ComputeWorldBound(time).ComputeAlignedBox() 可以获取世界坐标系下的版本。

prim_utils.py
def _compute_authored_world_bbox(prim: Usd.Prim) -> np.ndarray:
    imageable: UsdGeom.Imageable = UsdGeom.Imageable(prim)
    bound = imageable.ComputeWorldBound(Usd.TimeCode.Default(), UsdGeom.Tokens.default_)
    bound_range = bound.ComputeAlignedBox()
    return np.array([bound_range.min, bound_range.max])

优点：快，不需要遍历顶点。

缺点：可能包含不可见子层级、辅助几何、或者作者手误填错。

Mesh Points：几何的「铁证」

另一种方式是遍历所有 UsdGeom.Mesh Prim，读取 points 属性，用 ComputeLocalToWorldTransform 变换到世界空间，再取 min/max。

prim_utils.py
def _compute_single_mesh_point_bbox(prim: Usd.Prim):
    points = prim.GetAttribute("points").Get()
    points = np.array(to_list(points), dtype=float)
    xform = np.array(imageable.ComputeLocalToWorldTransform(time), dtype=float)
    points_h = np.hstack([points, np.ones((points.shape[0], 1))])
    points_world = np.dot(points_h, xform)[:, :3]
    return np.array([np.min(points_world, axis=0), np.max(points_world, axis=0)])

优点：只包含实际可见的几何，不受 authored extent 错误影响。

缺点：慢，需要递归遍历所有子 Prim；如果 points 里有 NaN，需要额外清理。

remder-usd 的双策略

compute_bbox() 函数实现了智能 fallback：

  1. 先算 authored_bbox
  2. 再算 mesh_bbox（递归遍历所有可见 mesh）
  3. 如果 authored_diagonal / mesh_diagonal >= extent_fallback_ratio（默认 5.0），说明 authored extent 异常大，回退到 mesh_bbox
  4. 如果 authored bbox 的中心与 mesh bbox 中心偏移超过 mesh 对角线（center_offset_ratio >= 1.0），也说明 extent 不可信，回退到 mesh_bbox
工程智慧：永远不要信任单一数据源。生产管线中，authored metadata 和 computed geometry 应该互相校验，不一致时取更保守（更小/更准）的那个。
