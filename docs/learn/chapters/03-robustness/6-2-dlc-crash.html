Segmentation Fault 全复盘：DLC Crash Fix

2026-03-04，DLC 分布式渲染任务频繁崩溃（exit code 139）。所有资产都渲染成功了，却在 shutdown 时 segfault。这是一次经典的 GPU 资源泄漏导致的崩溃。

时间线

10:42:08　Job Created

10:46:34　Job Started

10:50:12　First Render（第一个钢琴资产开始渲染）

10:50:37　Last Render（全部 10 个钢琴渲染完成，耗时 25 秒）

10:53:15　Job Failed（exit code 139，SIGSEGV）

关键发现：崩溃发生在渲染完成后 3 分钟，正在执行 kit.close()。所有输出文件都已正常生成。

根因分析

Isaac Sim 的 shutdown 流程需要释放大量 GPU 资源：

  • Camera render products（GPU framebuffer）
  • Camera custom annotators（Replicator 节点）
  • USD imaging delegate 缓存（Hydra 的 GPU 数据结构）
  • Python 对象的循环引用（导致 GC 无法回收）

如果这些资源没有被显式清理，kit.close() 会在释放 USD stage 和 GPU context 时访问已失效的指针，触发 segfault。

修复方案

Fix 1：RenderManager.cleanup()

renderer.py
def cleanup(self):
    for camera in self.cameras:
        if hasattr(camera, '_custom_annotators'):
            camera._custom_annotators.clear()
        if hasattr(camera, '_render_product'):
            camera._render_product = None
    self.cameras = []
    if self.world:
        self.world.reset()
    gc.collect()

Fix 2：Shutdown 顺序

cli.py
# ✅ 正确顺序
renderer.cleanup()   # 先释放 GPU 资源
gc.collect()         # 再强制 Python GC
kit.close()          # 最后关闭 Isaac Sim
结果：修复后 DLC 任务 exit code 从 139 变为 0，峰值内存下降 30-50%，单 asset 失败不再导致整 job 崩溃。
