MDL 材质路径修复与材质系统

渲染结果全红？多半是 MDL 材质路径断了。render-usd 的 mdl_utils.py 提供了一套自动修复机制。

MDL 是什么

MDL (Material Definition Language) 是 NVIDIA 开发的声明式材质语言。与 UsdPreviewSurface 不同，MDL 是「渲染器绑定」的：它直接描述光与表面的物理交互（BSDF），由目标渲染器编译执行。

GRScenes 数据集使用自定义的 KooPbr.mdl 材质，定义了 KooMtl 结构体，包含 base_color、metallic、roughness 等参数。

路径断裂的症状

  • 渲染结果全红（Isaac Sim 的「材质缺失」默认色）
  • 控制台出现 MDL compiler error: cannot find module '::KooPbr'
  • 某些物体显示为纯白色或纯黑色（fallback shader）

修复机制

mdl_utils.fix_mdls() 的核心逻辑：

  1. 遍历 Stage 上所有引用 MDL 的 Prim
  2. 检查 mdl:sourceAsset 和 mdl:module 属性中的路径
  3. 如果路径不存在，尝试用 DEFAULT_MDL_PATH 或搜索路径中的候选替换
  4. 通过 carb.settings.set_string_array("/app/mdl/additionalSystemPaths", [...]) 注册搜索路径
注意：MDL 修复必须在 SimulationApp 启动之后执行，因为 carb.settings 在启动前不可用。CLI 中通过 lazy import 保证了这一点。
