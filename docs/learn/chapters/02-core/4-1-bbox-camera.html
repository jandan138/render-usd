Bounding Box 驱动的相机距离

相机应该离物体多远？太近了塞满画面，太远了变成像素点。render-usd 的答案是：用 bounding box 的对角线长度决定 distance，确保画面 occupancy 约 60-65%。

算法：distance = bbox_diagonal × scale

renderer.py
bbox_min, bbox_max = compute_bbox(prim)
center = (bbox_min + bbox_max) / 2
distance = np.linalg.norm(bbox_max - bbox_min) * 1.0
distance = max(distance, 0.1)   # 防除零，防止相机钻到原点

这里的 1.0 是经验系数。结合 focal_length=18mm 和 512×512 分辨率，它恰好让大多数家具类资产占据画面 60-65%。

为什么用对角线而不是高度或宽度

因为物体的长宽比不确定。一张床可能很长（2m × 1.5m × 0.5m），一盏灯可能很高（0.3m × 0.3m × 1.2m）。用对角线 norm(bbox_max - bbox_min) 是最鲁棒的单一指标，能覆盖任意朝向的物体。

世界坐标系与局部坐标系

compute_bbox() 返回的是世界坐标系下的 (bbox_min, bbox_max)，不是局部坐标。这意味着即使物体被缩放、旋转、平移，算出来的相机距离仍然是正确的。

From GAMES101
课堂渲染器里，模型通常在局部坐标系内，你需要手动写 Model matrix 把它们变换到世界空间。USD 的 ComputeWorldBound 已经帮你做了这件事——它沿着 Prim 的层级累积所有父节点的变换，直接给出世界空间的包围盒。
