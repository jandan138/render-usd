Sensor Annotators：RGBA、Depth、BBox2D

Isaac Sim 的 Camera 不仅是「拍照」，它是一个多通道传感器。render-usd 中使用了 RGBA、BBox2D tight/loose，未来可扩展 Depth 和 Semantic Segmentation。

什么是 Annotator

在 Omniverse Replicator 框架中，Annotator 是一种渲染后处理节点。它在每帧渲染完成后，从 GPU framebuffer 中提取特定类型的数据，并维护一个内部缓存队列。

你可以把 Annotator 理解为「渲染管线的输出端口」：主渲染器生成图像后，不同的 Annotator 各自抓取自己关心的通道。

remder-usd 使用的 Annotator

Annotator注册方法输出形状用途
RGBAcamera.get_rgba()(H, W, 4) uint8带 alpha 的原始渲染图
BBox2D Tightadd_bounding_box_2d_tight_to_frame()(N, 6) float32紧贴物体轮廓的 2D 框
BBox2D Looseadd_bounding_box_2d_loose_to_frame()(N, 6) float32包含透明/模糊边界的宽松框
Depthadd_distance_to_image_plane_to_frame()(H, W, 1) float32到像平面的距离（可转点云）
Semantic Segadd_semantic_segmentation_to_frame()(H, W, 1) int32每个像素的语义类别 ID

BBox2D 数据结构

每个 BBox2D 记录包含 6 个字段：

python
(id, x_min, y_min, x_max, y_max, occlusion_ratio)
# 例如：(0, 120.5, 80.3, 400.2, 430.1, 0.0)

render-usd 中利用 tight 和 loose 的面积比来过滤无效检测：如果 area(tight) / area(loose) < 0.8，说明 BBox 不可靠（可能是遮挡或渲染伪影），跳过保存。

注意：BBox2D annotator 依赖语义标签。如果 add_update_semantics() 没有被正确调用，annotator 返回空数组。
