View 命名约定：front / left / back / right

render-usd 支持两种输出命名风格：index（_0.png, _1.png…）和 view（front.png, left.png…）。理解它们的映射关系，是下游任务对接的前提。

两种命名风格

风格文件名适用场景
index{object}_0.png, {object}_1.png...通用批量处理，机器友好
viewfront.png, left.png, back.png, right.png人类可读，VLM 标注对接

命名映射逻辑

renderer.py
if naming_style == "view" and sample_number == 4 and init_azimuth_angle == 0:
    view_names = {0: "front", 1: "left", 2: "back", 3: "right"}
    filename_base = view_names[idx]
else:
    filename_base = f"{object_name}_{idx}"

约束：view 命名只在 sample_number=4 且 init_azimuth_angle=0 时有效。如果用户自定义了视角数量或起始角度，view 命名会 fallback 到 index，防止语义混乱。

坐标系约定

在 Isaac Sim 的默认右手坐标系中（Z 向上）：

  • +X = Front：物体正面朝向 +X 方向时，azimuth=0° 看到的就是 front view
  • +Y = Left：从 +Y 方向看向原点，即物体的左侧
  • -X = Back：与 +X 相反
  • -Y = Right：与 +Y 相反
注意：这与某些 3D 软件（如 Blender 的 -Y front）不同。render-usd 遵循 Isaac Sim / USD 的坐标约定，+X 为 front。
