NaN / Inf 检查：数值稳定的最后一道防线

USD 文件来自不可控的外部来源，顶点数据可能包含 NaN 或 Inf。如果不检查，这些坏值会沿着管线传播，导致相机位置异常、segfault、或全黑/全白的渲染结果。

NaN/Inf 从哪来

  • 损坏的 USD 导出：某些 DCC 工具（3ds Max、Maya 插件）在导出时可能产生未初始化的顶点
  • 除零：齐次坐标变换中 w=0 会导致 x/w = Inf
  • 骨骼动画退化：某些 pose 下权重矩阵奇异，变形后的顶点坐标变成 NaN

remder-usd 的三层防御

第一层：Prim 创建后验证

renderer.py
usd_prim = create_prim(show_prim_path, ...)
if usd_prim is None or not usd_prim.IsValid():
    print(f"[Error] Failed to create valid prim for {object_usd_path}")
    delete_prim(show_prim_path)
    continue

第二层：Bounding Box 数值检查

renderer.py
if np.any(np.isnan(bbox_min)) or np.any(np.isnan(bbox_max)):
    print(f"[Error] Invalid bounding box (NaN) for {object_name}, skipping")
    delete_prim(show_prim_path)
    continue
if np.any(np.isinf(bbox_min)) or np.any(np.isinf(bbox_max)):
    print(f"[Error] Invalid bounding box (Inf) for {object_name}, skipping")
    delete_prim(show_prim_path)
    continue

第三层：Mesh 顶点清理

prim_utils.py
if np.isnan(points).any():
    nan_mask = np.isnan(points).any(axis=1)
    valid_points_mask = ~nan_mask
    # 重新建立 faceVertexIndices 映射，丢弃含 NaN 顶点的面
    old_to_new_indices = np.full(points.shape[0], -1)
    old_to_new_indices[valid_points_mask] = np.arange(np.sum(valid_points_mask))
    valid_faces_mask = np.all(old_to_new_indices[faceVertexIndices] != -1, axis=1)
工程铁律：在数据流入算法核心之前，永远校验数值有效性。单个坏资产不应该搞垮整个批量任务。
