Center-offset 陷阱与 fallback 策略

有些 USD 资产的 authored extent 包含了远离几何中心的辅助节点（如 locator、light、camera rig），导致包围盒中心与实际 mesh 中心相差甚远。相机看向错误中心，物体就会偏出画面。

真实案例

假设一个台灯资产：

  • Mesh 实际占据：[-10, -10, 0] 到 [10, 10, 30]（单位：cm）
  • 但 authored extent 包含了一个位于 (0, 0, 500) 的辅助 locator
  • 结果：authored bbox 中心在 (0, 0, 265)，mesh 中心在 (0, 0, 15)，相差 250cm

如果相机看向 (0, 0, 265)，实际台灯只在画面底部露出一小部分，大部分画面是空白。

Center-offset Ratio 检测

prim_utils.py
def _bbox_center_offset_ratio(authored_bbox, mesh_bbox) -> float:
    authored_center = (authored_bbox[0] + authored_bbox[1]) / 2.0
    mesh_center = (mesh_bbox[0] + mesh_bbox[1]) / 2.0
    mesh_diagonal = np.linalg.norm(mesh_bbox[1] - mesh_bbox[0])
    if mesh_diagonal <= 0:
        return 0.0
    return float(np.linalg.norm(authored_center - mesh_center) / mesh_diagonal)

当这个 ratio >= 1.0 时，意味着 authored center 偏离了至少一个 mesh 对角线的距离。这对 thumbnail 来说是致命的——物体会严重偏出画面。

Fallback 决策树

start → 计算 authored_bbox

　　→ 计算 mesh_bbox（递归遍历）

　　　　→ mesh_bbox 无效？→ 返回 authored_bbox

　　　　→ authored_bbox 含 NaN/Inf？→ 返回 mesh_bbox

　　　　→ authored_diagonal / mesh_diagonal >= 5.0？→ 返回 mesh_bbox

　　　　→ center_offset_ratio >= 1.0？→ 返回 mesh_bbox

　　　　→ 否则 → 返回 authored_bbox
